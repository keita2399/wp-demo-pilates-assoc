# WordPress試作：指導者養成団体サイト（架空の団体）

団体サイトのリニューアル提案のために作った WordPress の試作です。団体名・人物・スタジオ・料金・日程はすべて架空のダミーデータです。

## 開く

https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/keita2399/wp-demo-pilates-assoc/main/blueprint.json

ブラウザの中で WordPress が立ち上がります（サーバー不要、30秒ほどかかります）。管理者でログインした状態で開くので、管理画面（左上の「ピラティス指導者協会」→ ダッシュボード）も操作できます。何を変えても、URLを開き直せば最初の状態に戻ります。

## 試していること

1. 料金はコースの編集画面にだけ入力する。コース紹介、料金一覧、開催日程、トップページ、本文中の料金表記（ショートコード）はすべてその値を表示する。開催日程には料金の欄が無い。
2. 訪問者の目的ごとに入口を分ける（資格を取りたい方／資格をお持ちの方／スタジオを探す方）。
3. 認定スタジオと認定インストラクターを、地方・都道府県・器具・資格で絞り込める。
4. 開催日程を月のカレンダーと一覧で表示し、コース・地方・形式で絞り込める。
5. 旧サイトのURLから新しいURLへ301で転送する表を、管理画面で1行1件で管理する（例：/course/mat1/ → /courses/mat-1/）。
6. 権限グループ「事務局」：お知らせ・日程・料金・スタジオ・固定ページの文章は更新できるが、デザイン・プラグイン・ユーザー・設定には触れない。
7. 外部プラグインは使わない。機能はすべてテーマの inc/ に、用途ごとのファイルとして置く。

## 試し方の例

1. 管理画面「コースと料金」→「マット1」を開き、受講料を変えて「更新」
2. 公開側の「料金」「開催日程」「よくある質問」を開き直す → すべて新しい金額になっている
3. 公開側で /course/mat1/ を開く → /courses/mat-1/ に転送される

事務局の画面を見る場合は、一度ログアウトしてユーザー名 jimukyoku、パスワード jimukyoku-demo でログインしてください（この試作の中だけのアカウントです）。

## ファイル

| ファイル | 内容 |
|---|---|
| inc/post-types.php | コース・開催日程・認定スタジオ・認定インストラクター |
| inc/meta.php | 入力欄と保存。コースの「この料金が表示されている場所」 |
| inc/helpers.php | 料金・日程の読み出し（料金はここを通してしか読まない） |
| inc/shortcodes.php | 本文中の料金表記 [course_price course="mat-1"] |
| inc/redirects.php | 旧URLの301転送 |
| inc/admin.php | 一覧の列、「このサイトの仕組み」、転送表の画面 |
| inc/roles.php | 権限グループ「事務局」 |
| inc/security.php | バージョン非表示、XML-RPC停止、ユーザー名の漏えい防止など |
| inc/seed.php | ダミーデータ |
